# b64file (English)

Browser-only Base64 tools, English edition of b64file.cn. Same tool, retargeted at
English-language search demand and meant to live on its own domain behind a global CDN
(Vercel / Cloudflare Pages) so Google and Bing can index it properly.

## What is here

- **22 public pages** (1 home + 19 tool/guide pages + about/privacy/terms) plus a 404 shell
- Conversion runs **entirely in the browser**: no backend, no upload, no account
- Pages are generated at build time with per-page title, description, canonical,
  `hreflang` pairs to the Chinese site, JSON-LD (`WebApplication` / `Article` / `FAQPage`)
- `dist/llms.txt` is generated for AI search engines (GEO)
- `dist/sitemap.xml` + `dist/robots.txt` are generated by the prebuild step
- An IndexNow key file is created on first build so Bing/Yandex instant indexing works out of the box

## Commands

```bash
pnpm install
pnpm dev        # local dev server
pnpm test       # 91 tests
pnpm build      # tsc + vite build  → dist/
pnpm preview    # serve the build locally
```

## Configuration

Everything environment-specific lives in `site.config.json`:

| key | meaning |
| --- | --- |
| `siteUrl` | production origin, no trailing slash. Drives canonical, OG, sitemap, hreflang |
| `brand` | brand name used in the header, footer and JSON-LD |
| `feedbackEmail` | contact address in the footer and legal pages |
| `ga4Id` | GA4 measurement ID (`G-XXXXXXX`). Empty = analytics off |
| `zhSiteUrl` | Chinese site origin, used for the zh/en `hreflang` pair. Empty = no hreflang |

Change a value there and rebuild — no other file hardcodes the domain or brand.
